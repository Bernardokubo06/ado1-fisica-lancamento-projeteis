ADO 1 - Física: Lançamento de Projéteis

Aplicação em Python com interface gráfica para simular um lançamento de projétil ideal, sem resistência do ar.

Requisitos:
Python 3.10 ou superior

Matplotlib

Tkinter (normalmente já vem com o Python no Windows)

O que o programa faz?

Permite informar velocidade inicial, ângulo, altura inicial e gravidade.

Atualiza a trajetória e os resultados calculados.

Exibe alcance horizontal, altura máxima e tempo de voo.

Anima o projétil pelo botão Lançar.

Permite guardar trajetórias para comparação.

Trata entradas inválidas com mensagens amigáveis.

Mantém a mesma escala nos eixos do gráfico.
